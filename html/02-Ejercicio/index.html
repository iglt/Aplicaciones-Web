WORLD WIDE WEB

En informática, la World Wide Web (WWW) o Red informática mundial comúnmente conocida como la Web , es un sistema de distribución de documentos de hipertexto o hipermedios interconectados y accesibles vía Internet. Con un Navegador web, un usuario visualiza sitios web compuestos de páginas web que pueden contener texto, imágenes, vídeos u contenidos multimedia, y navegar a través de esas páginas usando enlaces.
